# SETU Frontend

Offline-capable field app and command centre for SETU disaster response.

- `apps/field` — volunteer field app (offline-first reports, household registration, sync)
- `apps/command` — command centre (map, flood/road/settlement layers, routes, evacuation)
- `packages/*` — shared contract types, API client (mock | http), mock backend test double, UI
- `docs/API_CONTRACT.md` — DRAFT API contract proposal for backend review

All frontend work lives under `frontend/`. Backend directories are owned by the backend lead.
